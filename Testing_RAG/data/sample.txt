Clear Bill is a billing and management system built for a clinic or hospital setting. It is a full-stack web application, with a React-based frontend and a Node.js/Express backend connected to a MySQL database.

The purpose of the system is to manage the flow of patients, medical services, and payments in a healthcare setting. Instead of one generic view, the app gives each type of user their own dashboard and set of permissions, based on their role:

- Admins oversee the system as a whole, including users and general settings.
- Doctors can view patient information and record the services they provide.
- Receptionists handle patient registration and scheduling.
- Cashiers process payments and generate bills for services rendered.
- Patients can log in to see their own bills and payment history.

Users log in through a shared login page, and the system uses JSON Web Tokens (JWT) to keep track of who is logged in and what they're allowed to access. Passwords are stored securely using bcrypt hashing rather than in plain text.

Behind the scenes, the backend is organized around a handful of core concepts: patients, services, bills, bill details (the individual line items on a bill), payments, and users. Each of these has its own database model, along with routes and controllers that handle creating, viewing, and updating that data. For example, when a doctor records a service for a patient, that eventually becomes a bill, which a cashier can then take a payment against.

The frontend is a single-page application, with separate sections (pages) for each role's dashboard, and shared elements like a header and navigation bar. It uses Tailwind CSS for styling and Recharts to show data visually, such as charts summarizing billing activity.

In short, Clear Bill is a role-based hospital billing platform that connects the clinical side (patients and the services they receive) with the financial side (bills and payments) in one system.
